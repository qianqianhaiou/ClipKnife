文档状态：产品事实源

## 1. 文档定位

《ClipKnife 产品基线手册》是 ClipKnife 的底层产品文档。它记录当前产品的功能、概念、使用路径、状态反馈、边界和限制，是后续营销、推广、对外发布、帮助文档、FAQ、演示脚本和版本说明的统一事实来源。

本手册不记录代码实现细节。它关注用户能看到、能理解、能操作、能依赖的产品行为。

## 2. 产品定位

ClipKnife（素刀）是一款本地素材管理、智能检索与辅助创作工具，面向拥有大量本地图片、视频和音频素材的创作者。

它的核心目标是让用户把分散在文件夹、盘符和外接硬盘中的素材统一纳入本地素材库，通过 AI 索引、视频分镜、代表帧、语音转写和自然语言搜索快速找回可用素材，并继续组织成可编辑的剪映草稿或交给本地创作工具处理。

ClipKnife 的核心价值：

- 本地优先：素材文件留在用户电脑中，核心建库和检索在本机完成。
- 多源统一：多个文件夹、盘符和外接盘可以汇总成一个素材库。
- AI 可检索：图片、视频片段和音频/视频语音内容可以被自然语言搜索。
- 视频片段化：视频通过分镜和代表帧变成可搜索、可预览、可导出的片段。
- 创作工作流衔接：素材和分镜可以加入项目，并拖拽到外部创作软件或导入区。
- 创作助手协同：用户可以用自然语言检索素材、创建或编辑剪映草稿，并保留可继续调整的时间线。
- 本地工具按需使用：文本转语音、图片清晰化和视频增强独立安装，在本机处理输入内容。

## 3. 核心概念

### 3.1 素材源

素材源是 ClipKnife 扫描和监听的本地范围。它可以是一个普通文件夹、整个盘符或外接硬盘路径。

每个素材源拥有独立的路径、名称、启用状态、监听意图、访问状态、扫描状态和排除规则。素材源不可访问时，ClipKnife 会提示异常，但不应影响其他可用素材源继续工作。

### 3.2 素材库

素材库是多个素材源汇总后的统一素材空间。用户在素材库中浏览的是所有已入库的本地素材，而不是单个目录。

素材库当前支持图片、视频和音频。用户可以按类型筛选，也可以搜索文件名、路径和标签等信息。

### 3.3 AI 索引

AI 索引是 ClipKnife 支持智能搜索的基础。素材被扫描入库后，ClipKnife 会为可检索内容创建索引。

- 图片：直接进入视觉检索索引。
- 视频：先分镜，再抽取分镜代表帧，代表帧进入视觉检索索引。
- 音频：转写成语音文本后进入语音检索索引。
- 视频语音：开启视频语音转写后，视频中的语音内容也可以进入语音检索索引。

索引可能处于待处理、处理中、成功、失败或失效状态。索引未准备好时，智能搜索会给出明确提示。

### 3.4 分镜

分镜是视频被自动切分后的片段。每个分镜记录起止时间、代表帧、处理状态和可编辑信息。

分镜让长视频可以以片段为单位被搜索、预览、标注、加入项目和导出。

### 3.5 语音转写

语音转写把音频或视频中的语音内容转换成可搜索文本。

音频素材始终会生成可搜索的语音转写。视频语音转写由系统设置控制，开启后 ClipKnife 会为视频素材补建或新增语音转写任务。

### 3.6 项目

项目是用户临时组织素材和分镜的工作空间。用户可以把素材库或搜索结果中的素材、视频分镜加入项目，然后从项目中拖拽到外部导入区。

项目不会删除原始素材文件。删除项目会删除项目记录和项目文件夹中的导出内容；从项目中移除条目只影响项目自身。

### 3.7 任务

任务是后台处理动作，包括扫描素材源、发现素材、素材入库、重扫素材源、构建索引、重试失败任务、重建语音索引、删除索引等。

任务中心展示任务进度、状态、失败原因和可恢复入口。

### 3.8 诊断

诊断用于检查本地环境、素材源、任务队列、索引和搜索服务是否可用。诊断包默认脱敏路径，不复制用户素材源文件，搜索历史默认不导出。

### 3.9 工具箱

工具箱承载由 ClipKnife 客户端预先适配的创作工具。工具种类、操作界面和调用方式由客户端版本决定；远程服务只提供已知工具的版本、下载直链和发布说明，不能向客户端动态增加未知工具。

工具箱首页以卡片列出客户端已经适配的“文本转语音”“图片清晰化”“视频增强”和“视频拆分镜”四个工具。前三项是按需下载的工具：未安装时只能发起安装，安装完成后才能进入工具详情；某个工具尚未在服务端发布安装包时，卡片仍可识别该工具，但不能凭空安装。客户端会在启用前校验 HTTPS 下载地址、压缩包大小与哈希、版本清单、包内精确文件集合及逐文件哈希，并校验工具标识、运行契约和版本。“视频拆分镜”复用随应用安装的 TransNetV2 与 ffmpeg/ffprobe 组件，不从工具目录单独下载安装；组件缺失时卡片显示不可用，并由组件管理负责修复或替换。

“文本转语音”从本机已安装的 `tts.exe` 实时读取可用音色，不在客户端代码中维护固定音色表。用户可输入最长 50,000 个字符的文本并生成一个 WAV 文件，长文本会自动分段处理后合并。工具详情的最近生成列表支持试听和在文件夹中显示结果。

“图片清晰化”使用本机 Real-ESRGAN NCNN Vulkan 工具处理单张 JPG、PNG 或 WebP 图片，提供通用照片/实拍与动漫/插画模型、2×/3×/4× 放大、PNG/JPG/WebP 输出、显存分块和可选 TTA。透明图片无法安全写入 JPG 时，结果按工具的实际输出保存为 PNG。它只读取原图，结果写入应用管理的工具箱输出目录，不覆盖输入文件。

“视频增强”使用本机 Video2X，可单独提升视频分辨率、使用 RIFE 提升帧率，或按“先提升分辨率、再提升帧率”的顺序连续处理。动漫视频分辨率模型支持 2×/3×/4×，通用实拍和动漫高质量模型仅支持 4×；用户还可选择 RIFE 模型、2×/4× 帧率和可选 UHD 模式。当前结果统一输出为 MP4。组合模式只保留最终结果，正常完成、失败或取消后都会清理中间文件，原视频不会被覆盖。

“视频拆分镜”允许用户选择一个本地视频并调整 TransNetV2 切换阈值，先生成按时间排序的镜头边界，再勾选一个或多个镜头交给 FFmpeg 逐帧精确转码。精确导出不使用关键帧近似截取，结果写入应用管理的工具箱输出目录；分析记录可再次打开并继续导出。分析和导出都不会覆盖原视频，工具箱导出的镜头也不会自动加入素材库或索引。

创作助手可以调用已经安装的文本转语音工具。工具安装后，对话输入区会显示音色入口；用户通过弹窗查看本机工具实时返回的音色列表，并可按名称、语言或音色标识筛选。没有安装文本转语音工具时不显示音色入口。用户确认选择后，后续新对话默认恢复上一次仍然可用的音色，原音色已不可用时回退到当前列表中的第一个音色。生成的音频直接保存在当前创作会话的工作区中，不写入工具箱输出目录，也不出现在工具箱的最近生成列表。如果当前会话已经选择草稿，默认把生成音频放到从 0 秒开始的独立“AI配音”音频轨道；用户明确要求只生成文件时不修改草稿。加入草稿失败时，已经生成的音频文件仍会保留并给出部分成功提示。

创作助手还注册了视频拆分镜、外部视觉描述和 FFmpeg 媒体处理工具。视频拆分镜先分析镜头边界，再按分析结果精确导出助手选择的镜头；结果只保存在当前创作会话工作区，不自动加入工具箱历史或素材索引。FFmpeg 工具允许助手组合多个已授权的本地输入并生成最多八个声明输出，但执行在受限媒体沙箱中：输入必须来自当前会话已授权的素材或文件，输出只能进入当前会话工作区，禁止任意本机路径、网络地址、标准输入输出管道、脚本和可间接读取其他资源的参数。未提交结果、中间文件和未声明的附带输出在失败、取消或完成后清理。

### 3.10 创作助手

创作助手是把素材检索与剪映草稿操作连接起来的对话式工作区。它不是只返回建议的聊天入口，而是通过本地草稿服务实际创建或编辑剪映草稿，并在会话中展示素材检索、草稿修改和导出等工具步骤。

首次使用前，用户需要在“创作助手设置”中选择剪映草稿根目录和默认导出目录，并配置至少一个可用模型。新建会话会锁定当时选择的模型配置；后续调整默认模型不会改变已有会话的模型快照。会话支持搜索、重命名和删除，删除会话不会删除用户的原始素材文件。

创作助手可以搜索 ClipKnife 素材库中的图片、视频片段和音频，使用素材 ID、片段时间和已有视觉描述判断素材是否适合当前创作。用户可以为会话限定一个素材目录，限定后本地图片、视频和相似素材检索都不能静默回退到全库；音频仍从全局素材库检索。用户也可以显式附加本地文件或素材库条目，目录范围不会排除本轮主动附加的文件。

会话尚未绑定草稿时，创作助手会创建一个不重名的新草稿。只有用户在当前指令中明确点名并要求继续、修改、替换或复用旧草稿时，助手才会打开已有草稿。助手可以添加视频、图片、音频和文字轨道，处理字幕、转场、滤镜、动画、蒙版、关键帧、淡入淡出和背景填充，也可以替换模板素材或文字、保存草稿并导出成片。操作结果保留为可继续编辑的剪映草稿。

“自动”模式会根据用户指令自主完成创作，不在普通剪辑步骤中逐项提问；遇到重名草稿或导出文件时使用不重名的新名称。“询问”模式会在开始编辑前集中确认素材、最终文案和背景音乐一次，确认后自主完成普通剪辑步骤。永久删除草稿始终需要明确审批，持久化修改 Skill 也始终需要界面确认。剪映桌面自动导出开始后不能取消，用户需要保持素刀和剪映运行，最长可能等待约 20 分钟。

创作过程中发送的新消息会按顺序接入当前任务，用户也可以在导出开始前停止本轮生成。工具失败时，界面应展示真实错误和可执行的恢复建议，不能把未生成的草稿或成片描述为成功结果。

创作助手支持按需检索 Openverse、Wikimedia Commons、Pexels、Pixabay、Coverr、Jamendo 和 Freesound。外部素材默认不允许访问；“询问”模式在当前会话首次需要联网时请求一次授权，“自动”模式只有在当前指令明确授权时才可检索。授权或拒绝会在当前会话中保留。部分来源需要用户配置 API Key，密钥只保存在本机服务。结果展示来源、作者和许可信息，用户选中的素材会先下载到当前会话工作区，再交给本地草稿服务使用。

### 3.11 创作助手模型配置

创作助手的固定模型供应商目录由素刀远程服务下发，目录只包含供应商名称、API Base URL、可选模型 ID、每个模型的上下文长度、可选配置说明简介和链接等公开元数据。客户端按服务端顺序展示固定供应商；供应商名称、Base URL 和模型上下文长度由服务端维护，模型 ID 只能从服务端提供的选项中选择，用户再填写 API Key、选择思考强度并测试连接。服务端提供配置说明简介或链接时，客户端通过 warning 提示卡展示说明，并在有链接时附上完整教程入口。未配置的固定供应商不影响保存，已经配置的供应商可设为默认。

用户也可以添加本地自定义供应商，自定义配置只支持 OpenAI Compatible 协议。自定义供应商的上下文长度由用户设置，默认是 256k（262,144 tokens）。用户确认风险后可以删除自定义供应商；历史会话内容仍会保留，但依赖该供应商的会话无法继续对话。API Key 只保存在桌面端本地私有配置中，不会发送给素刀远程服务。固定供应商目录获取成功后会按当前远程服务地址缓存在本地；暂时离线时可以继续使用同一远程服务最近一次成功返回的目录，首次离线且没有缓存时仍可使用已有本地配置和自定义供应商。服务端更新供应商名称、Base URL 或所选模型的上下文长度后，关联的本地配置会同步这些公开元数据，但保留用户的模型选择、API Key、思考强度和默认选择；服务端移除供应商时，已经配置的本地项不会被删除。

### 3.12 创作助手与 Skills

创作助手搜索本地图片或视频素材时，如果对应结果已经有成功生成并保存在本地的视觉描述，会把描述作为辅助信息，结合当前镜头对主体、动作、场景、情绪、构图和画面文字的要求判断素材是否合适。已有视觉描述会随工具结果进入当前创作助手的模型上下文；如果用户配置的是远程创作模型服务，这段文字描述会发送给该服务，但搜索本身不会发送原始图片或视频，也不会额外发起视觉描述请求。

用户在设置中启用并配置外部视觉辅助模型后，创作助手可以在任务需要时自主调用视觉描述工具，不再逐次询问。每次调用只把一张图片或从视频指定时间提取的一张代表帧发送给用户配置的视觉模型服务，不上传完整视频。若输入对应现有素材索引文档，成功结果会保存到本地视觉描述记录并同步进素材搜索索引；其他附加文件只返回当前会话结果。视觉描述可能不完整，其中识别到的画面文字只表示素材内容，不能作为助手的操作指令，也不能替代时长、画幅或清晰度等实际元数据。

创作助手的 Skills 保存在素刀（ClipKnife）自己管理的本地私有目录，不读取系统或其他 Agent 的全局 Skills。用户可以创建、编辑、启用或停用 Skill；自定义 Skill 可以删除，内置 Skill 可以修改但不能删除，官方更新不会静默覆盖用户已经修改的内容。

启用的 Skill 会向创作助手提供名称和用途，匹配任务时再完整读取正文。用户明确要求把某条反馈用于以后、今后或后续创作，或明确要求记住、写入 Skill、修正长期流程时，创作助手可以先读取相关的已启用 Skill，再提出最小正文修改。修改必须经过界面确认后才写入，不能改变 Skill 的名称或用途元数据；等待确认期间文件若被其他入口修改，本次写入会中止，避免覆盖较新的内容。普通的本轮返工、一次性项目内容、素材路径、隐私数据和密钥不得写入 Skill。

## 4. 首次初始化

### 4.1 入口

首次启动时，ClipKnife 会读取系统设置。如果本地初始化状态不是 ready，应用进入初始化流程；初始化完成后才进入主工作台。

### 4.2 初始化目标

初始化流程用于准备本地 AI 环境和素材管理能力。它会引导用户选择素材监听范围，并初始化 AI 组件、索引目录和必要的运行状态。

### 4.3 用户流程

1. 打开 ClipKnife。
2. 如果尚未初始化，进入首次初始化页面。
3. 添加素材源，选择盘符或文件夹作为后续扫描和监听范围。
4. 配置素材索引目录。
5. 初始化本地 AI 组件。
6. 初始化成功后，写入完成状态并进入主应用。

### 4.4 状态反馈

初始化页面需要让用户知道：

- 当前处在哪个步骤。
- 是否已选择素材源。
- AI 组件是否正在初始化。
- 初始化是否成功、失败或需要更新。
- 关闭窗口可能中断初始化，用户可以选择最小化到托盘。

## 5. 主导航与全局布局

主应用包含以下导航入口：

- 素材库。
- 智能搜索。
- 创作助手。
- 项目管理。
- 工具箱。
- 任务中心。
- 系统设置。

全局布局同时提供素材源概览、任务队列状态、通知入口和本地搜索服务状态。任务队列入口聚焦处理中或等待中的任务，通知入口展示未读数量和刷新状态。

### 5.1 工具箱状态与隐私边界

工具安装、更新、语音生成、图片清晰化、视频增强和视频拆分镜会显示实时进度，并同步出现在任务中心。媒体处理可取消，未提交的输出和中间文件会清理；应用重启不会自动重跑已经中断的工具处理，避免重复生成。由工具详情生成的结果保存在工具箱输出目录并进入对应工具的最近记录；由创作助手生成的语音、分镜和 FFmpeg 结果只保存在对应会话工作区。

工具箱中的四个工具都在本机处理内容。远程服务只接收下载型工具的目录查询和安装包下载所需的签名请求，不接收输入图片、视频、文本正文或本机输入路径。文本转语音调用所需的实例标识由本地核心服务读取或生成并持久化，渲染界面、远程服务、日志和诊断包都不接收这些标识；输入正文不会写入任务记录或本地数据库。

## 6. 素材源管理

### 6.1 功能定位

素材源管理用于配置 ClipKnife 的扫描和监听范围。它解决素材分散在不同文件夹、盘符、外接盘中的问题。

### 6.2 入口

素材源管理可从系统设置进入，也可在素材库空状态、初始化流程和其他引导入口中打开。

### 6.3 添加素材源

用户可以添加一个或多个素材源。添加时 ClipKnife 会执行预检，并识别以下情况：

- 路径是否存在。
- 路径是否可访问。
- 是否与已有素材源重复。
- 是否与已有素材源存在父子路径重叠。
- 是否是盘符或外接盘等高风险扫描范围。

当预检发现风险但仍可继续时，ClipKnife 会要求用户确认。

### 6.4 素材源状态

素材源列表展示每个素材源的基本信息和运行状态，包括访问状态、扫描状态、监听状态、最近更新时间等。

用户可以启用、停用或移除素材源。移除素材源会移除 ClipKnife 对该范围的管理，不代表删除原始文件。

### 6.5 初始建库与监听

添加素材源后，ClipKnife 可以启动素材监听，并创建初始建库任务。初始建库会扫描已启用素材源，把支持的图片、视频和音频加入素材库，并创建后续索引任务。

监听用于捕获素材源中的后续变化，避免新增、修改或删除素材长期与素材库不一致。

### 6.6 排除规则

对盘符级或范围较大的素材源，ClipKnife 应避免扫描系统目录、缓存目录、开发依赖目录和自身工作目录。排除规则用于降低误扫、慢扫和权限失败风险。

## 7. 素材库

### 7.1 功能定位

素材库是用户浏览、筛选、预览和进入素材详情的主入口。它按导入时间展示素材，支持卡片网格和快速预览。

### 7.2 统计信息

素材库展示素材总量和不同类型数量，包括图片、视频和音频。它也展示 AI 搜索相关统计，例如已索引、待处理或失败任务数量。

### 7.3 搜索与筛选

用户可以在素材库中搜索文件名、路径和标签，并按素材类型筛选。素材库搜索不同于智能搜索，它主要基于素材元信息，而不是自然语言语义检索。

### 7.4 素材卡片

素材卡片用于展示文件名、类型、路径、预览缩略图和可执行操作。用户可以选择素材、打开原文件、打开所在目录或查看详情。

音频素材提供音频播放入口。视频和图片素材提供对应预览和详情入口。

### 7.5 素材详情

素材详情展示文件基础信息、路径、索引状态和相关处理结果。

图片详情展示图片索引状态、最近索引时间和错误信息。视频详情展示视频索引状态、分镜数量、已索引帧数量和分镜预览。音频详情展示语音转写内容和索引状态。

### 7.6 空状态

当没有素材时，素材库提示用户添加素材源并启动初始建库。扫描完成后，素材会自动刷新到素材库。

## 8. 智能搜索

### 8.1 功能定位

智能搜索让用户用自然语言搜索本地素材。用户不需要理解底层模型、索引或分镜流程，只需要输入画面或语音内容描述。

### 8.2 搜索模式

智能搜索支持以下模式：

- 全部：混合返回图片、视频片段和音频结果。
- 图片：搜索图片素材。
- 视频：搜索视频分镜代表帧或视频语音片段。
- 音频：搜索音频素材和视频语音内容。

### 8.3 查询输入

用户可以输入中文或英文描述，例如“搜索画面内容，如一群在河边喝水的大象”。空查询会提示用户输入搜索内容。

### 8.4 结果展示

搜索结果以网格或列表展示。结果包含缩略图或媒体预览、文件名、路径、匹配类型、相似度或相关性信息，以及打开原文件、打开所在目录、查看详情等操作。

视频结果会展示片段起止时间。音频和视频语音结果会展示转写文本。视频语音结果在产品上属于视频结果，但命中来源是语音转写。

### 8.5 排序与筛选

搜索支持智能排序、相似度排序、修改时间排序和文件名排序等方式。不同模式下可用排序可能不同，例如语音模式会优先突出转写文本的命中。

### 8.6 以图搜图

图片和视频代表帧结果可以触发以图搜图，用当前结果作为相似检索入口，返回视觉上相近的素材。

如果当前结果缺少可用的相似检索索引 ID，ClipKnife 会提示需要重新构建 AI 索引。

### 8.7 搜索历史

ClipKnife 保存本地搜索历史。用户可以复用历史搜索词，也可以清空搜索历史。

### 8.8 错误与引导

搜索页覆盖以下状态：

- 输入为空。
- AI 索引尚未准备好。
- 搜索服务不可用。
- 没有找到匹配素材。
- 文件不可访问，可能已移动或素材源已断开。
- 当前结果无法进行以图搜图。

当索引或搜索服务异常时，搜索页会引导用户前往诊断。

## 9. 视频详情与分镜

### 9.1 入口

用户可以从素材库或智能搜索的视频结果进入视频详情。视频详情用于播放视频、查看分镜、编辑片段信息和导出片段。

### 9.2 视频预览

视频详情提供真实视频预览，并默认启用音频播放。用户可以选择分镜，视频播放位置会与选中片段关联。

### 9.3 分镜列表

分镜列表展示每个片段的顺序、起止时间、缩略图、状态和可编辑信息。用户可以选择分镜查看详情。

### 9.4 分镜信息

分镜信息面板展示片段基础字段、时间范围、备注、标签和转写文本。转写文本来自覆盖该片段起止范围的语音转写结果。

### 9.5 分镜编辑

用户可以执行以下分镜编辑操作：

- 调整分镜起止时间。
- 更新备注和标签。
- 合并分镜。
- 分割分镜。
- 删除分镜。

这些操作作用于 ClipKnife 的分镜记录和项目工作流，不直接破坏原始视频文件。

### 9.6 片段导出

用户可以导出选中片段，也可以导出全部片段。导出会创建后台任务，并把结果写入指定输出目录。导出成功后，用户会看到导出路径。

片段导出用于把视频中的可用片段沉淀成独立文件，方便后续剪辑或归档。

### 9.7 与搜索索引的关系

分镜和代表帧是视频视觉搜索的基础。调整分镜信息可能影响后续搜索结果展示和片段解释；如果索引缺失或失败，用户需要重新构建相关索引。

## 10. 音频与语音检索

### 10.1 音频素材

ClipKnife 支持把音频素材作为素材库的一类资源。音频素材可以播放、查看详情，并通过语音转写参与搜索。

### 10.2 音频预览

用户可以从素材库或搜索结果打开音频预览。音频预览提供播放器，并展示可用的转写文本。

如果音频路径不可访问，ClipKnife 会提示无法创建本地播放地址。

### 10.3 语音搜索

语音搜索基于转写文本。用户可以搜索音频中的语音内容，也可以在开启视频语音转写后搜索视频中的语音内容。

音频模式返回音频片段和视频语音片段。视频语音片段会保留视频身份，方便用户回到视频上下文。

### 10.4 视频语音转写设置

系统设置中提供视频语音转写开关。音频素材始终生成可搜索转写；视频素材需要开启该开关后才会生成视频语音转写。

用户可以手动补建缺失转写，ClipKnife 会创建对应后台任务。

## 11. 项目管理

### 11.1 功能定位

项目管理用于把分散找到的素材或视频分镜组织成可拖拽的工作集合。它面向剪辑、设计和素材整理流程。

### 11.2 新建项目

用户可以创建项目，填写项目名称和描述。项目会拥有独立目录，用于保存项目内的导出内容和拖拽所需文件。

### 11.3 添加素材到项目

用户可以从素材库、搜索结果或视频详情中的相关入口把素材加入项目。可加入项目的对象包括完整素材和视频分镜。

添加完成后，ClipKnife 会提示已添加到对应项目。

### 11.4 项目列表与项目详情

项目管理页展示项目列表、项目素材数量和可拖拽数量。用户选择项目后，可以查看项目内素材和分镜。

项目条目标识其类型，例如素材或分镜，并显示就绪、处理中或失败等状态。

### 11.5 拖拽导入

项目提供“拖拽项目至导入区”的能力。只有已就绪的项目条目会进入拖拽载荷；缺失或未就绪条目会被跳过。

### 11.6 删除与移除

删除项目会移除项目记录和项目文件夹中的导出内容，操作不可撤销。移除项目素材只会从当前项目中移除，不会删除原始素材文件。

移除分镜会从当前项目中移除该分镜，并删除项目内生成的分镜文件；原始视频不会被删除。

## 12. 任务中心

### 12.1 功能定位

任务中心用于观察后台任务状态，定位失败素材，并执行重试或恢复操作。

### 12.2 任务类型

任务中心覆盖以下用户可理解的任务类型：

- 扫描素材源。
- 发现素材。
- 素材入库。
- 重扫素材源。
- 重试索引失败任务。
- 重建语音索引。
- 删除语音索引。
- 安装或更新创作工具。
- 生成语音。
- 图片清晰化。
- 视频增强。

### 12.3 状态筛选

任务中心提供任务状态筛选，包括全部任务、等待、处理中、完成和失败等视图。用户可以在刷新过程中继续查看已有内容。

### 12.4 失败素材

任务中心提供“索引失败素材”入口，展示解析或索引失败的素材。用户可以查看文件、类型和失败原因，并根据情况修复源文件、恢复外接盘、重试任务或重新建库。

### 12.5 空状态

没有任务时，任务中心提示用户：启动素材扫描后，扫描和入库任务会显示在这里。

## 13. 系统设置

系统设置用于管理本地运行环境、素材源和全局配置。它包含常规设置、素材源管理、诊断与修复、关于等分类。

### 13.1 常规设置

常规设置包含：

- 开机自启：Windows 登录后让 ClipKnife 进入托盘并保持素材源监听。
- 关闭窗口行为：每次询问、最小化到托盘或直接退出。
- 视频语音转写：控制是否为视频素材生成可搜索语音转写。
- 补建缺失转写：为缺失语音转写的素材创建后台任务。

如果关闭窗口行为设为最小化到托盘，后台任务和监听会继续运行。

### 13.2 AI 与媒体组件设置

设置页展示并管理与本地处理相关的组件配置，包括：

- TransNetV2：用于视频分镜。
- ffmpeg/ffprobe：用于视频索引、分镜读帧、代表帧抽取和片段导出。
- imsearch：用于视觉检索、相似检索和语音检索索引。
- 语音转写组件：用于音频和视频语音转写。

这些组件的配置影响本地 AI 能力是否可用。

组件管理会展示 imsearch 与 TransNetV2 的当前版本、运行版本，以及服务端当前软件版本发布记录中的配套版本。本机组件与配套版本不一致时，应用会提示用户前往软件网盘下载配套组件压缩包，再由用户在组件管理中确认并完成替换；组件包不会静默自动安装。

### 13.3 素材源管理入口

系统设置中提供素材源管理入口，用户可以查看、添加、启用、停用或移除素材源，并启动相关建库流程。

### 13.4 诊断与修复

诊断与修复汇总环境、素材源、任务队列、索引与搜索服务的可用性。

用户可以执行只读健康检查。只读检查不会修改任务、索引或素材文件。

修复操作先执行预览，确认后才写入任务或标记索引记录。典型修复包括：

- 重试失败任务。
- 清理失效图片索引。
- 清理失效视频索引。
- 压缩搜索索引。
- 重启搜索服务。

### 13.5 导出诊断包

用户可以导出诊断包。诊断包默认脱敏路径，不包含素材源文件，搜索历史默认不导出。

诊断包只包含环境、任务、索引和日志摘要，用于问题排查。

### 13.6 系统更新

系统设置提供检查更新入口。ClipKnife 可以检查 stable 发布渠道中的最新版本，并区分全量安装包和增量更新包。

当存在可用更新时，用户可以查看更新说明、更新包类型、全量更新阈值，并下载更新。

如果当前版本落后多个已发布版本，更新提示会按版本从新到旧列出期间所有更新说明，避免遗漏中间版本内容。

检查更新也会比较本机 imsearch、TransNetV2 与最新发布记录中的对应组件版本。组件需要更新时，即使主程序已是最新版，应用仍会给出组件更新提示和软件网盘入口。

### 13.7 通知

ClipKnife 提供通知入口，展示来自远程服务的通知。通知可以刷新、标记已读，并展示未读数量。

通知类型包括信息、警告和更新提示。

### 13.8 服务端广告

ClipKnife 可以展示由素刀远程服务发布的图片广告。固定广告位包括工具箱首页工具列表之前、任务中心任务列表顶部、创作助手侧边栏已用素材列表顶部、智能搜索初始空状态顶部，以及已选项目的素材列表顶部。没有命中广告、广告图片无效或广告位当前不满足展示条件时，不保留空白占位。

广告只有图片、可选“广告”标识和按策略显示的关闭按钮，点击图片只允许打开服务端配置的 HTTPS 地址。服务端可以设置投放时间、优先级、投放设备、排除设备和关闭策略；排除设备优先于包含规则，每个广告位同一时间最多展示一条广告。

关闭策略分为三种：常显广告不提供关闭按钮；临时关闭会在当前设备隐藏 24 小时；永久关闭会立即在本地隐藏，并在联网后同步到远程服务，后续不再显示同一广告。曝光只在广告连续至少 1 秒有 50% 面积可见时记录，并在单次应用会话内对同一广告最多记录一次；点击会逐次记录。

### 13.9 关于

关于页展示产品名称、版本、核心能力描述和开源项目致谢。

## 14. 远程服务能力

ClipKnife 是本地优先产品，但可以接入远程服务完成以下辅助能力：

- 检查更新。
- 拉取通知。
- 标记通知已读。
- 拉取适用于当前设备的广告，并下载通过完整性校验的广告图片。
- 上报广告曝光、点击和永久关闭事件。
- 获取已知创作工具的版本和下载地址。

远程服务不承担本地素材内容处理职责。素材扫描、索引、搜索、分镜和转写的核心工作仍以本地环境为主。

## 15. 隐私与本地文件边界

ClipKnife 的产品边界遵循以下原则：

- 不复制用户素材到诊断包。
- 移除素材源不删除原始文件。
- 从项目中移除素材不删除原始文件。
- 视频分镜编辑不直接破坏原始视频文件。
- 诊断包默认脱敏路径，搜索历史默认不导出。
- 外接盘断开或路径失效时，ClipKnife 提示异常，但不应影响其他素材源。
- 创作助手的 API Key 和外部素材库密钥保存在本机私有配置中，不发送给素刀远程服务。
- 创作助手的对话文本、启用 Skill、工具结果、视觉描述、素材引用信息以及用户主动选择的本地文件路径会进入模型上下文，并直接发送给用户配置的创作模型供应商。启用外部视觉辅助模型后，创作助手还可按任务需要把一张图片或一张视频代表帧发送给用户配置的视觉模型供应商；不会发送完整视频，也不会把原始媒体发送给素刀远程服务。
- 外部素材检索会把检索词发送给获得授权的第三方素材服务，选中的结果会下载到当前创作会话工作区。用户应根据来源页面和许可信息判断是否适合使用。
- 工具箱中的文本、图片和视频由本机工具或随应用提供的媒体组件处理，远程服务不接收输入正文、媒体内容或本机输入路径。
- 广告投放与统计只向素刀远程服务提供广告 ID、行为类型、设备码、应用版本、系统名称/版本和发生时间，不包含搜索词、素材路径、素材内容、转写文本或创作内容；临时关闭状态只保存在当前设备，永久关闭会同步到远程服务。

## 16. 已知限制

当前产品边界包括：

- 不包含账号系统。
- 不包含云同步。
- 不包含多人协作。
- 不包含素材交易市场；外部素材检索仅用于按需访问第三方开放来源。
- 不包含商业化付费逻辑。
- 不承诺自动理解完整视频语义，视频视觉检索主要基于分镜代表帧。
- 搜索结果依赖本地索引质量，索引未完成或失败会影响可搜索范围。
- 搜索服务不可用、模型组件缺失或外接盘断开时，相关能力会降级或提示错误。
- 创作助手不是完全离线能力，需要连接用户配置的模型供应商；使用外部素材库时还会访问获得授权的第三方服务。
- 创作助手创建、编辑和导出剪映草稿依赖配套的本地草稿组件与剪映桌面端，导出开始后不能取消。

## 17. 功能变更沉淀规则

每次代码改动完成后，都必须判断是否需要更新本手册。

需要更新的情况包括：

- 新增、删除或改变用户可见功能。
- 改变用户流程、入口、导航、按钮、设置项或默认行为。
- 改变素材源、素材库、搜索、索引、分镜、转写、项目、任务、诊断、更新、通知等核心能力。
- 改变状态、错误提示、限制、失败恢复方式或隐私边界。
- 改变可对外宣传的产品能力。

更新时只记录产品事实，不记录内部实现细节。营销、发布、帮助和对外说明应优先从本手册抽取。
