# ClipKnife 产品基线文档

本目录存放 ClipKnife 的产品事实源文档。

## 文档命名

本产品的核心文档命名为：

**《ClipKnife 产品基线手册》**

英文辅助名：**Product Baseline Manual**。

它不是传统意义上的“需求文档”，也不只是终端用户的“使用手册”。它记录当前产品已经具备、已经对用户呈现、可以被复用到外部表达中的功能事实。

## 文档职责

`manual/product-baseline.md` 是以下内容的上游基座：

- 官网、落地页、宣传物料和销售话术。
- 发布说明、更新日志和版本亮点。
- 用户帮助、FAQ、教程和演示脚本。
- 后续产品需求拆解和体验验收。
- 对外介绍 ClipKnife 时需要保持一致的产品口径。

它只关注产品功能和用户可感知行为，不写内部代码结构、函数名、接口实现、数据库表设计或构建细节。

## 与 docs/ 的关系

- `manual/`：当前产品事实源。描述产品是什么、能做什么、用户如何理解它。
- `docs/`：历史需求、开发设计、阶段计划、第三方调用和技术说明。可以作为编写手册时的参考材料，但不是最终产品口径。
- `DESIGN.md`：UI 视觉与交互实现规范。它约束界面一致性，不替代产品基线。

当 `docs/` 与 `manual/product-baseline.md` 对同一功能的表述不一致时，营销、发布、帮助文档优先以 `manual/product-baseline.md` 为准；如果代码行为变化导致手册过期，应先更新手册。

## 维护规则

每次完成代码改动后，检查是否影响以下任一产品事实：

- 新增、删除或改变用户可见功能。
- 改变用户流程、入口、导航、按钮、设置项或默认行为。
- 改变素材源、素材库、搜索、索引、分镜、转写、项目、任务、诊断、更新、通知等核心能力。
- 改变状态、错误提示、限制、失败恢复方式或隐私边界。
- 改变对外可宣传的能力或已知限制。

如果有影响，必须同步更新 `manual/product-baseline.md`。更新时写清楚用户能感知到的结果，不要把代码实现细节搬进手册。
