# 素刀（ClipKnife）

> 用一句话，找回你散落在硬盘里的每一帧灵感
>
> 中文 | [English](./README.en.md)

素刀是一款面向创作者的 Windows 本地素材管理与自然语言检索工具。把分散在文件夹、盘符和外接硬盘里的素材加入素材库，完成本机索引后，可以用画面描述查找图片或视频片段，再回到原文件核对、整理和使用。

**本仓库用于官网、使用手册、更新日志和问题反馈，不包含桌面应用源代码。** 使用软件请从官网下载，不需要克隆本仓库或搭建开发环境。

- [官网下载](https://clipknife.cn/)
- [使用手册](https://clipknife.cn/manual/) · [常见问题](https://clipknife.cn/faq/) · [更新日志](https://clipknife.cn/changelog/)
- [按内容查找本地视频的操作说明](https://clipknife.cn/scenes/search-video-content/)

## 适合解决什么问题

- 文件名记不住，但还记得画面：例如“海边日落”“红色包装特写”。这些是描述方式示例，不是检索成功率测试。
- 素材分散在多个目录或硬盘，希望从同一个素材库检索。
- 视频较长，希望从搜索结果定位到相关分镜，而不只是找到整个文件。
- 找到素材后，需要按项目整理，或交给剪辑软件继续使用。

素刀不是完整的视频剪辑软件，也不提供云同步或多人在线协同编辑。搜索结果仍需打开原片确认；代表帧可能遗漏短暂画面，自动分类和人物分组也可能出错。

## 从建库到使用素材

1. 从官网下载并安装，按应用提示完成联网激活和所需组件初始化。
2. 先添加一个较小的素材文件夹，确认路径可访问，再扩展到其他素材源。
3. 等待扫描和索引完成。图片建立视觉索引；视频自动分镜、抽取代表帧，并关联原视频时间段。首次建库时间取决于素材规模和硬件，不承诺固定速度。
4. 在智能搜索中输入画面描述，或使用以图搜图。需要检索语音时，先开启对应的转写开关并完成索引。
5. 播放命中的片段核对内容，再打开原文件、导出片段或整理到项目。需要送入剪映或 Premiere Pro 时，按手册检查目标时间线和版本兼容条件。

## 当前能力与边界

| 能力 | 可以做什么 | 使用前要知道 |
|---|---|---|
| 本地素材管理 | 管理图片、视频、音频及多个素材源，跟踪扫描和索引任务 | 外接盘或源目录离线时，原文件可能无法打开 |
| 画面检索 | 用自然语言或图片查找本机图片、视频分镜 | 依赖已完成的索引；不是逐帧检索，不能保证每次命中 |
| 语音检索 | 转写音频或视频中的语音，再搜索文本对应的时间段 | 音频、视频转写分别控制，默认关闭；首次启用需下载组件 |
| 分镜查看与导出 | 预览分镜、编辑镜头级标签、导出选中或全部片段 | 不提供备注编辑、手工调整起止时间、合并、拆分或删除分镜 |
| 项目管理 | 将找到的素材和分镜组织成工作集合 | 不是云端协同项目；共享库结果不能直接加入本机项目 |
| 创作助手 | 按对话组织素材、生成文本或配音，并创建和编辑剪映草稿 | 需要配置模型服务；最终在剪映检查并导出成片，不由助手直接导出 |
| 工具箱 | 文本转语音、图片清晰化、视频增强、批量视频拆分镜 | 工具与组件按需安装；批量视频拆分镜是自动导出功能，不是手工编辑分镜边界 |
| 局域网共享 | 在可信局域网内只读搜索和使用另一台电脑发布的素材 | 默认关闭；共享端需保持运行、授权有效且素材可访问，不是云同步 |

“添加到剪映 / PR”每次处理一项本地图片、完整视频或分镜，追加到已有时间线；不自动创建草稿、项目或序列，不支持直接添加共享库素材。剪映和 PR 的适配版本、连接组件与限制见 [v2.4.0 更新说明](https://clipknife.cn/changelog/v2.4.0/)，不要将其理解为所有版本均已验证。

## 运行环境

当前公开下载面向 **Windows 11（x64）**，运行内存 **16GB 及以上**；没有 macOS 或 Linux 安装包。完整要求与下载版本以官网为准。

- **本机核心检索可使用 CPU**，兼容的 GPU 可用于加速；这一点不代表所有可选功能都支持 CPU。
- **本地视觉描述模型**需要兼容的 NVIDIA 显卡，至少 4GB 显存、推荐 6GB，不提供 CPU 推理。当前 CUDA 13 组件要求计算能力至少 7.5、Windows 驱动至少 580.88；不满足要求的旧卡不能运行该本地视觉组件。该门槛不套到 CPU 或 AMD 的核心搜索组件。
- **图片清晰化与视频增强**需要支持 Vulkan 的显卡；不能把核心搜索的 CPU 支持套用到这两项工具。

安装组件、建库和媒体处理需要额外磁盘空间。具体兼容性以对应版本日志及应用内组件检查为准，不承诺某台机器的速度或检索准确率。

## 隐私与联网：按功能区分

**本地优先不等于所有功能完全离线。**

- **本机处理**：核心建库、索引、搜索、分镜和已安装组件的转写在本机运行，不因这些操作向素刀公网服务上传原始素材。
- **局域网共享**：局域网共享默认关闭，仅用于可信局域网，采用 HTTP 明文传输。搜索词、主动选择的查询图片、结果预览及按需原文件会在两台设备间传输，不经素刀公网服务中转；不要向公网开放共享端口。
- **外部模型**：启用外部视觉 API 后，会按功能把选定图片或视频采样帧发送给你配置的供应商；远程创作模型会收到相关对话和描述文字。不要将这些功能描述为“任何数据都不离开本机”。
- **产品服务**：联网激活、许可验证、更新检查、通知及组件下载需要访问相关服务。使用前请确认所需许可与组件有效。

完整的数据传输范围和开关说明见[使用手册](https://clipknife.cn/manual/)。
