# 使用手册图片放置说明

把使用手册截图放在本目录，文件名如下：

- `01-first-launch.png`：首次启动与初始化界面。
- `02-add-source.png`：添加素材源和预检提示。
- `03-library.png`：素材库列表、筛选和素材卡片。
- `04-smart-search.png`：智能搜索输入、模式切换和结果列表。
- `05-video-scenes.png`：视频详情、分镜列表和片段信息。
- `06-task-center.png`：任务中心、失败素材和重试入口。
- `07-settings-diagnostics.png`：系统设置、诊断与修复入口。
- `08-diagnostics.png`：诊断与修复检查结果。
- `09-system-update.png`：系统更新与组件更新提示。

以下创作功能截图已在手册中预留位置，补图前不会出现在正文页面：

- `10-creative-assistant.png`：创作助手对话、素材引用和草稿执行状态。
- `11-creative-assistant-settings.png`：创作助手通用设置与模型配置。
- `12-toolbox.png`：工具箱列表、安装状态和更新入口。
- `13-toolbox-tts.png`：文本转语音配置与最近生成列表。
- `14-toolbox-image-enhance.png`：图片清晰化参数和处理结果。
- `15-toolbox-video-enhance.png`：视频增强参数、进度和处理结果。
