开始之前，了解这些条件

先建索引，再按内容搜索

扫描入库与 AI 索引需要时间，速度取决于素材量、格式与硬件。目录监听跟踪所选范围；原文件移动或磁盘离线后，需要恢复可访问路径。索引和缓存仍会占用磁盘空间。

根据功能准备硬件与组件

素刀面向 Windows x64，运行内存至少 16GB。基础图像检索可以使用 CPU；本地视觉描述与语音转写按各自的硬件、模型和自检要求启用。查看硬件说明。

片段衔接需要配套环境

PR 入口需要“素刀连接”0.2.0 或更新插件及 Windows Premiere Pro 26.0 及以上，当前已验证 26.0.0；其他版本未逐版验证，首版不支持 PR 25.x 和 macOS。剪映也需要匹配版本与草稿服务。查看完整配套条件。

按实际功能理解数据边界

本机建库、搜索、分镜或转写不会向素刀公网服务上传原始素材。激活、许可验证、下载与更新等需要联网。主动启用局域网共享会在授权设备间传输数据；使用外部模型时，相关内容会发给你配置的供应商。查看传输范围。

Eagle 已有 AI 搜索，素刀的侧重点是什么？

Eagle AI Search 已有本地以图找图，以及基于已有文字信息的自然语言搜索；AI Action 还能帮助补足素材描述。素刀的侧重点是把本地图片与视频分镜的画面直接纳入视觉索引，并把结果连接到时间范围、转写和后续素材使用。两种流程都需要前期准备，适合用自己的素材与查询核对效果。[2][3]

已经用 Eagle，是否要迁移整个资源库？

可以先选择一份可访问的本地素材文件夹体验素刀，原有 Eagle 工作流继续使用。本页不承诺直接读取 Eagle 私有资源库、继承标签与评分，或同步两边的分类。需要从 Eagle 取出素材时，使用其官方导出方式，再按普通文件接入。[5]

视频搜索适合查找哪些内容？

视频视觉搜索基于分镜采样画面，结果提供对应的原视频和时间范围。它不代表逐帧理解，短暂出现的内容或复杂情节仍可能漏检。语音搜索需要先开启对应转写并建立索引，使用结果前应结合原片核对。

分类整理会影响原文件吗？

智能分类先给出候选，由你确认后归类；分类整理不会移动、重命名或删除原文件。同一素材可以进入多个分组，移出或删除分组不删除原始素材。其他明确的文件删除操作有各自的确认流程。
