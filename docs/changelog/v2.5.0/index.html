v2.5.0

发布时间：2026-10-23

适用系统：Windows x64

发布通道：stable

发布状态：已发布

本次更新新增视频理解与高光工具，开放独立 Agent 的 MCP 创作能力，改进视频分镜检索，并支持后台准备更新、下次启动安装。

MCP：让外部 Agent 调用素刀能力

  • 重建 MCP 创作接口。受信任的本机 Agent 可按授权独立调用素材搜索、分类词云、语音转写、视觉描述、人物分析、分镜分析、配音、剪映草稿及外部素材检索等能力，由 Agent 或自定义 Skill 组织工作流。
  • 系统设置提供 MCP 总开关与独立授权管理，服务默认关闭。可分别选择能力、素材源和剪映草稿目录，每个 Agent 使用独立凭据，可单独撤销；完整凭据仅在创建时显示一次。
  • 素材源授权控制库内访问，Agent 也可直接读取本机媒体文件进行分析。普通分析结果、配音和下载素材自动保存在应用数据目录；本地转写、视觉和人物分析不会自动回退到外部模型。
  • 长任务支持查询进度、取消和显式重试；剪映修改结果不明确时不会自动重复执行。使用旧 MCP 接入的用户，需要重新创建授权并更新客户端工具配置。

视频理解与高光：理解原片，挑选片段

  • 新增“创作工具 → 视频理解与高光”入口，使用本地 MiniCPM-V 4.6 分析单个不超过 6 小时的视频，生成理解报告、事件时间线和高光候选。
  • 默认结合画面与对白：优先使用视频旁有效的同名 SRT，否则使用已配置的本地语音转写与精确对齐；无音轨时自动跳过对白，也可主动选择“仅分析画面”。
  • 可填写关注点，选择综合精选、剧情与情绪、观点与演示或动作与结果，并设置片段长度偏好和候选上限。高光候选经过更密集的画面复核，展示推荐理由与相关字幕或转写文本，可按推荐度或原片顺序查看。
  • 支持预览原视频、手动调整或还原候选起止时间、批量选择并导出独立 MP4。输出保存到应用下载目录，可直接打开所在位置，不覆盖原视频。
  • 显示实际分析覆盖比例和未完成时间段，任务中心可查看分析与导出进度、取消任务；中断后可保留已完成进度，由用户继续分析。
  • 本功能仍标记为实验功能，需要配套的本地视觉模型与按需使用的语音资源。长视频分析耗时较长，模型可能误解人物、对白或情节；覆盖比例不代表识别准确率，没有可靠高光时允许空结果，导出前请结合原片核对。

视频检索：自适应多帧索引

  • 配套新版图像检索组件后，较长分镜会比较中间及靠近首尾的画面，保留有明显差异的样本，每个分镜最多索引 3 帧；不超过 3 秒的分镜仍使用中间帧。
  • 搜索结果按分镜合并，预览对应实际命中的采样画面，减少只看中间帧时遗漏首尾内容的情况。分镜数量、标签和字幕仍以分镜为单位。
  • 旧索引不会自动补帧；需要对选定视频重新索引，才能使用多帧结果。旧组件仍沿用单中间帧方式，此能力不代表逐帧检索或完整理解视频。

更新体验：后台准备，下次启动安装

  • 新增默认开启的“自动更新”开关，位于“系统设置 → 关于软件”。发现更新仍会弹出说明；关闭提示后，开关开启时才在后台下载安装包和必需组件，准备期间可继续使用当前版本。
  • 下载与校验完成后等待下次启动安装，不主动重启；从托盘恢复窗口不会触发安装。关闭开关会停止自动下载并阻止下次自动安装，手动“立即更新”仍可使用。
  • 加快日常版本检查；手动更新显示下载、文件校验和运行库准备状态，启动安装显示组件进度。兼容的程序小包可复用已有运行库，缺失或损坏时补下载基础包。
  • 安装前仍会联网复核发布状态并校验文件与签名；断网或复核超时继续启动现有版本。修复组件更新重复重启、批量安装失败等问题。

稳定性与日常使用

  • 修复人脸组件在中文路径下初始化失败的问题，改善人物详情查询和人物复核时的响应，减少对本地服务其他请求的阻塞。
  • 改进许可检查暂时不可用后的恢复与搜索诊断，区分许可状态和搜索进程状态，避免把暂时的连接问题误判为搜索服务退出。
  • 修复首次建库激活、组件导入恢复及旧版索引队列相关问题，完善应用重置后的状态清理。
  • 使用统计按小时汇总固定功能次数与脱敏硬件信息，可在隐私设置中关闭；不包含原始素材、完整本机路径、搜索词或转写文本。

升级说明

  • 在“系统设置”中检查软件及配套组件更新。多帧索引等能力需要匹配的组件；自动后台准备从升级至本版本后生效，可选工具和语音、视觉模型仍按需安装。
  • 升级前可备份应用数据，并保持素材源与数据磁盘可访问。本版本不改变此前的 CUDA 13 显卡兼容要求。
