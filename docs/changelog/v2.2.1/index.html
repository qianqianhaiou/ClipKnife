v2.2.1

发布时间：2026-09-28

适用系统：Windows x64

发布通道：stable

发布状态：已发布

版本概览

v2.2.1 为素刀（ClipKnife）加入建库后的应用数据迁移，并修复图片清晰化的倍率处理问题。任务中心也调整了已结束任务的排序，方便查看最近的处理结果。

应用数据迁移

  • 在“系统设置 → 数据与备份”中，可以把应用数据迁移到其他本地固定磁盘上的空目录。数据库、AI 组件、搜索索引、缓存、项目和日志会一起迁移；原始图片、视频和音频仍留在各自的素材源。
  • 迁移会等待正在进行的任务暂停，并显示复制与校验进度。切换前可以取消；全部校验完成后，点击“切换并重启”才会启用新目录。
  • 新目录首次启动验证失败时，应用会继续使用旧目录，并保留目标副本以便排查。验证成功后，应用会在后台确认旧目录内容未变化，再尝试清理；无法安全确认的旧目录会保留。独立存放在旧根目录之外的组件目录也会保留。

图片清晰化与任务中心

  • 修复图片清晰化使用 2×、3× 倍率时可能出现的分块错位。图片清晰化界面现在固定使用模型原生的 4× 放大；视频增强的倍率设置不受影响。
  • 任务中心将已完成、失败和取消的任务按结束时间从近到远排列，最近处理的任务更容易找到。

升级提示

  • 可在“系统设置”中检查更新。
  • 迁移前请确认目标磁盘有足够空间，并保持素材源和应用数据所在磁盘可访问。迁移应用数据不会移动原始素材。
  • 取消或失败后，目标磁盘上的暂存副本可能保留，可按页面提示查看其位置。
