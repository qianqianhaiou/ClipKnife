v2.0.0

发布时间：2026-08-30

适用系统：Windows

发布通道：stable

版本概览

v2.0.0 是素刀（ClipKnife）面向创作工作流的一次重大更新。在原有本地素材管理、AI 索引、智能搜索和视频分镜能力之上，本版本新增对话式创作助手与本地工具箱，让“找到素材”可以继续衔接到剪映草稿编辑、配音、图片清晰化、视频增强和镜头导出。

创作助手

  1. 新增对话式创作助手，可检索素刀素材库中的图片、视频片段和音频，并创建、打开、编辑与导出可继续调整的剪映草稿。
  2. 支持“自动”和“询问”两种工作模式。“询问”模式会在开始编辑前集中确认素材、最终文案和背景音乐；永久删除草稿等高风险操作仍需单独确认。
  3. 支持为会话限定素材目录，也可以主动附加本地文件或素材库条目；已有视觉描述会帮助助手判断素材是否适合当前镜头。
  4. 在用户授权后，可按需检索 Openverse、Wikimedia Commons、Pexels、Pixabay、Coverr、Jamendo 和 Freesound，并保留来源、作者与许可信息。
  5. 新增 6 个可编辑的内置 Skill，覆盖视频结构、视觉素材、音乐音效、转场特效、文字字幕和模板编辑。用户可让助手在确认后把长期反馈写入 Skill，逐步修正后续工作流程。
  6. 支持会话搜索、重命名、删除、历史恢复和连续追问；生成过程中发送的新消息会按顺序接入当前任务，导出开始前可以停止本轮生成。
  7. 支持选择本机文本转语音工具提供的音色。生成的配音可只保存为文件，也可加入当前草稿的独立“AI配音”轨道。

本地工具箱

  1. 新增“文本转语音”，支持从本机工具读取音色、处理最长 50,000 个字符的文本并生成 WAV 文件。
  2. 新增“图片清晰化”，使用 Real-ESRGAN 在本机处理 JPG、PNG 和 WebP 图片，支持照片与动漫模型、2×/3×/4× 放大和多种输出格式。
  3. 新增“视频增强”，使用 Video2X 在本机提升视频分辨率或帧率，也可以组合处理并输出 MP4。
  4. 新增“视频拆分镜”，使用内置 TransNetV2 分析镜头边界，支持调整阈值、选择镜头并通过 FFmpeg 逐帧精确导出。
  5. 工具支持按需安装、独立更新、完整性校验、实时进度、取消和最近结果记录；处理结果不会覆盖原始文件。
  6. 工具箱中的文本、图片和视频内容均在本机处理。素刀远程服务只参与工具目录查询与安装包下载，不接收输入正文、原始媒体或本机输入路径。

体验与可靠性改进

  1. 优化创作助手的消息展示、审批通知、历史会话恢复、素材结果选择和错误反馈。
  2. 优化内置模型供应商配置，并支持添加 OpenAI Compatible 自定义供应商。
  3. 工具安装、更新和媒体处理进度会同步到任务中心；失败、取消或应用重启后不会自动重复生成结果。
  4. 智能搜索组件与视频分镜组件升级到 v4.0.0，优化检索精准度和稳定性。

升级说明

  • v2.0.0 安装包、外部组件清单和校验信息将在正式发布时补充，请以官网首页与官方发布页为准。
  • 从旧版本升级前，建议先在“系统设置”中执行数据备份，并确保索引目录与素材源所在磁盘可正常访问。
  • 图片清晰化和视频增强依赖显卡；创作助手需要可用的模型供应商、配套草稿组件和剪映桌面端。
