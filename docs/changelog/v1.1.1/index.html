v1.1.1

发布日期：2026-07-31

适用系统：Windows

发布通道：stable

重要更新

  1. 优化底层检索模式，支持混合检索、视觉优先、文本优先和自定义标签。
  2. 新增素材盘模式；外接素材盘可在不同电脑上快速检索，无需重复建库。
  3. 修复超时、大数据量异常、HEVC 编码视频预览失败等已知问题。

本体更新

  1. 新增“补全缺失索引”功能，无需全量重建。
  2. 新增自定义 external 组件解压位置。
  3. 优化交互样式、以图搜图和素材对账等功能。

下载与升级

  • 增量安装包：素刀 v1.1.1 x64 安装程序
  • 全量安装包：百度网盘
从低于 v1.1.0 的版本升级时，请下载全量安装包；安装前请完全卸载旧版，并在卸载时勾选删除应用数据。
