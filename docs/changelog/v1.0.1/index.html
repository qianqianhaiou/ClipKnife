v1.0.1

发布日期：2026-06-24

发布类型：早期可用版本

v1.0.1 是 ClipKnife 对外提供下载与体验说明的早期版本，聚焦本地素材管理、自然语言搜索和官网下载入口。

新增

  • 建立官网页面，说明 ClipKnife 的产品定位、核心能力、适用人群和下载入口。
  • 提供百度网盘、夸克网盘和 GitHub Release 下载入口。
  • 补充中文 README，说明产品目标、核心工作流、隐私边界和项目状态。
  • 增加素材库、智能搜索、初始化和演示相关图片素材，用于官网和 README 展示。

产品能力说明

  • 支持把本地图片、视频和外接硬盘素材纳入素材库的产品说明。
  • 说明本地扫描、建库、分镜、索引和自然语言搜索的核心流程。
  • 强调素材处理以本地环境为主，素材文件不需要上传云端。
  • 说明视频素材通过分镜和代表帧参与检索。

已知限制

  • 当前版本仍处于早期阶段，文档和官网优先说明核心能力。
  • 项目仍聚焦 MVP 能力，部分入口和扩展能力会继续完善。
  • 搜索结果依赖本地索引质量，索引未完成或失败会影响可搜索范围。
