ClipKnife 更新日志

按发布日期倒序记录每个版本的功能变化、体验改进、组件版本与升级方式。

v1.1.6 2026-08-13 正式版本 提升智能搜索速度，支持视频分镜导出 GPU 加速与组件在线更新。 v1.1.5 2026-08-10 正式版本 支持数据备份与恢复，并可选用外部视觉辅助模型。 v1.1.4 2026-08-06 正式版本 按电脑性能调整初始建库批次，文件夹改名时自动迁移旧数据。 v1.1.3 2026-08-03 正式版本 优化分镜预览与分割精度，新增自动联播、画面方向筛选和组件替换。 v1.1.2 2026-08-01 正式版本 完善组件替换、指定范围检索、缺失索引补全和数据目录设置。 v1.1.1 2026-07-31 正式版本 支持补全缺失索引和自定义组件目录，并优化以图搜图与素材对账。 v1.1.0 2026-07-30 重大更新 新增多种智能检索模式与素材盘模式，改善大数据量和 HEVC 视频体验。 v1.0.7 2026-07-16 正式版本 支持外部 MCP 调用，并修复部分已知问题。 v1.0.6 2026-07-10 正式版本 支持以图搜索图片和视频，并优化大数据量下的虚拟列表缓存。 v1.0.5 2026-07-09 正式版本 优化大数据量下的建库、搜索能力、界面样式与问题排查手段。 v1.0.4 2026-07-08 正式版本 优化视频抽帧。 v1.0.3 2026-07-04 正式版本 完成底层重构，新增项目管理与以文搜音频，并优化批量任务。 v1.0.1 2026-06-24 早期可用版本 建立官网、下载入口、README 与核心能力说明。
