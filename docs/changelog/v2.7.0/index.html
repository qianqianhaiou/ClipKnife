v2.7.0

发布时间：2026-11-02

适用系统：Windows x64

发布通道：stable

发布状态：已发布

本次更新让素材查找与预览更直接：图片可从素材库查找相似内容，视频缩略图支持悬停定位与预览；同时改进批量分镜任务、历史视觉描述补建、索引检查恢复和启动体验。

图片查找相似

  • 素材库图片的右键菜单和“更多”菜单新增“查找相似”，可在弹窗中查找本机素材库里的相似图片与视频，继续筛选、预览或从结果再次查找相似；关闭弹窗后回到原来的素材库位置。
  • 使用图片已有的 AI 索引，未完成索引时会提示先构建索引。该入口始终查询本机素材库，不受智能搜索中已选共享库影响；原文件不可用时禁用入口。

视频悬停预览

  • 素材库时间线与灵感漫游中的视频缩略图支持悬停预览：鼠标左右移动定位画面，停留后静音播放；点击播放按钮或双击可从当前预览位置打开视频详情。位置线随预览移动，方便快速浏览长视频。
  • 本机文字搜索、以图搜图和相似搜索的视频结果也支持悬停预览，定位与播放限定在命中片段内，到片段末尾停止，时间标签显示原视频时间。共享素材暂不启用这项能力。
  • 支持键盘左右键定位、Esc 退出；启用系统“减少动态效果”时只定位画面。不支持内嵌播放的格式回退为按需采样画面；移出、滚动或打开详情后停止预览，避免多个视频同时加载。

批量分镜与视觉描述

  • “批量视频拆分镜”任务列表支持按文件名即时搜索，覆盖历史记录和所有任务状态，显示匹配数量与总数。搜索只筛选显示，“取消全部”“重试失败”和“清空历史”仍作用于全部任务。
  • “补建历史描述”先显示预计新增任务数，确认后才提交，取消不创建任务。统计会排除已有有效描述和队列中已有的任务，按图片或视频分镜分别计数；实际新增数量以提交结果为准。

索引检查与恢复

  • 配套更新图像索引组件后，常规启动和单纯异常退出后的启动改为轻量预检，全库检查由用户在“系统设置 → 诊断与修复 → 高级维护 → 索引检查”中手动发起。已有恢复保护、未完成的恢复操作或文件异常仍会提示处理。
  • 优化大素材库、多帧索引的检查效率，在任务中心展示数据库检查、向量分段校验和恢复复核等阶段及进度，减少诊断统计期间的界面等待。
  • 检查中退出应用后，下次启动会保留进度并提示手动继续；修复恢复完成后扫描仍停住、旧恢复任务干扰新恢复记录等问题，保留用户手动暂停的状态。
  • “重试全部失败”不再把失败的索引检查放回普通任务队列，避免持续等待。失败详情引导到诊断页重新检查；暂停或中断的检查仍可在任务中心继续。

任务、启动与兼容性

  • 改善大任务队列执行批量控制时的响应，减少暂停、继续等操作期间其他页面请求长时间等待的问题。
  • 启动更新期间收起“查看主窗口”入口；启动状态读取失败时同样保持入口关闭，避免提前进入尚未就绪的主界面。
  • 简易初始化的本地 AI 环境准备失败页新增“导出诊断包”，便于保留安装检查信息。诊断包不包含原始素材，不会自动上传。
  • 改进旧版素材盘快照导入兼容性，修复因旧快照缺少部分记录或字段不同而导入失败的问题。

升级说明

  • 在“系统设置”中检查软件及配套组件更新。索引启动与恢复改进需要同时更新桌面端和图像索引组件；升级前可备份应用数据，并保持素材源与数据磁盘可访问。
  • 索引检查与恢复仍保留确认边界，切换旧索引或重新建库需确认。本版本沿用此前的 CUDA 13 显卡兼容要求。
