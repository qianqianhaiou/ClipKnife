v2.0.1

发布时间：2026-09-02

适用系统：Windows x64

发布通道：stable

发布状态：已发布

版本概览

v2.0.1 为素刀（ClipKnife）带来一键更新和首次建库期间的部分搜索能力，让安装、升级和开始检索更加顺畅。

一键更新

  1. 在更新提示中点击一次“立即更新”，即可依次完成所需组件的下载与替换、软件安装包下载、校验、安装和重新启动，无需再手动打开安装程序。
  2. 每个版本统一使用一个 Windows 安装包，不再区分全量包与增量包；跨版本升级时，更新提示会汇总期间各版本的更新说明。
  3. 智能搜索与视频分镜组件可在线更新，也保留手动选择配套组件压缩包的方式。组件替换会等待相关任务结束，新组件验证失败时恢复旧组件。
  4. 组件更新失败、下载取消或安装包校验失败时，会停止软件安装并给出提示；软件安装开始前可以取消下载。

建库与搜索

  1. 首次建库期间，只要已有素材完成索引，即可在智能搜索中检索这部分素材，无需等待整个素材库处理完成。
  2. 搜索界面会提示索引仍在构建，可检索范围随建库进度逐步扩大。继续建库后重新搜索即可获得更多结果，当前结果列表不会自动跳动刷新。
  3. 修复智能搜索组件多次解压运行造成磁盘空间持续占用的问题，并完善组件检查与修复流程。

下载与升级

  • 安装入口见官网首页下载区。从尚不具备一键更新能力的V1旧版本升级时，需要先手动安装一次支持该能力的版本，后续更新即可在应用内完成。
  • 升级前可在“系统设置”中备份应用数据，并保持素材源与索引目录所在磁盘可正常访问。
