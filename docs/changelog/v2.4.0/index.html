版本概览

本次更新新增智能分类与词云，支持将本地图片、完整视频和视频分镜直接添加到剪映或 Adobe Premiere Pro，并加入最近标签与分镜循环播放。同时改进视觉描述、异常关机后的索引恢复和组件更新。

升级前请留意显卡兼容变化： NVIDIA 搜索与本地视觉描述改用 CUDA 13，GTX 1050 Ti 等旧架构显卡的搜索会回退 CPU，无法使用新版本地视觉描述。具体要求见下方“升级与兼容性”。

智能分类与词云

  • 素材库新增“智能分类”入口，按主体、动作、场景、氛围展示已有视觉描述中的高频词。可限定目录和素材类型，组合词条筛选图片与视频分镜。
  • 支持创建自己的分类：可保存词云组合为分类规则，也可按分类名称或库内参考图片查找候选，查看匹配依据后确认归类。同一视频的不同分镜可以分别归入不同分类，也可以属于多个分类。
  • 浏览时可直接预览图片或定位视频分镜；点击“编辑”后，可批量归类、确认或忽略候选，并调整、合并、拆分、隐藏或恢复词条。整理不会覆盖 AI 原始描述，也不会移动、重命名或删除原始文件。
  • 改进大素材库的统计、分页与批量处理，每张图片和每个分镜独立计数，减少同一分镜多帧带来的重复统计。统计和批量操作进入任务中心，可查看进度、暂停、取消或重试。
  • 智能分类目前面向本机图片和视频分镜；词云依赖已有视觉描述，名称与参考图候选需要配套新版图像组件。候选需由用户确认，不会仅凭相似画面自动归类。

一键添加到剪辑软件

本地素材的右键“添加到”菜单新增剪映与 Adobe Premiere Pro 入口。每次添加一张图片、一个完整视频或一个分镜，追加到当前时间线末尾的新轨道。分镜引用完整原视频及选定范围，进入剪辑软件后仍可在原素材范围内调整首尾，无需先导出裁短的文件。

剪映

  • 打开目标草稿后，在素材库、智能搜索结果或视频详情中右键选择“添加到 → 剪映”；有多个可用目标时，可选择要添加的草稿。
  • 当前适配 Windows 剪映 5.9.0.11632 与 11.6.0.14552，不代表兼容所有剪映版本。需要配套新版分镜组件；未打开草稿、组件缺失或版本不适配时会提示原因。

Adobe Premiere Pro

  • 配合“素刀连接”0.2.0 或更新插件，打开 PR 项目与活动序列，并保持“素刀连接”面板打开，即可从右键菜单添加素材，无需手动复制配对信息。
  • 可在“系统设置 → 剪辑软件”查看连接状态、暂停或重新连接；素刀服务重启后，插件可自动恢复连接。支持 Windows Premiere Pro 26.0 及以上，已在 26.0.0 实机验证，其他版本尚未逐版验证；首版不支持 PR 25.x 和 macOS。
  • 插件安装、连接与分镜首尾调整方法见 Premiere Pro 使用说明。

两种联动均暂不支持单独添加音频或直接添加共享库素材，也不会自动新建草稿、项目或序列。添加结果可在任务中心查看；若提示结果未确认，请先检查剪辑软件中的时间线，再决定是否重试，避免重复添加。

最近标签与分镜预览

  • 图片和视频分镜共用本机最近使用的标签，下拉选中即可添加，也可继续手动输入。最多保留 100 个最近标签，重启后继续可用；当前素材已有的标签不会重复列出。
  • 视频详情新增“分镜循环”开关，可反复播放当前分镜，包括视频末尾的最后一个分镜；切换分镜时同步切换循环范围。开关默认关闭，关闭后从当前位置继续正常播放。
  • 修复视频播放与暂停状态不同步的问题，改善打开标签编辑弹窗及关闭后的播放状态恢复。

视觉描述与组件更新

  • 改进中文描述、标点和常见术语的识别与校验，减少有效描述被误判为格式错误。需要纠错时优先处理有问题的字段，保留可用内容，减少重复生成。
  • 本地视觉模型支持优先使用完整、匹配的离线组件；缺少可用离线包时，经用户确认后再联网下载。改进安装检查与失败反馈，已有有效描述不因组件升级而要求全库重建。
  • 搜索与本地视觉复用匹配的 CUDA 运行依赖，减少重复占用；改进搜索及剪映相关组件的程序小包更新。本机依赖不完整或不兼容时，仍需使用完整组件包。

索引恢复与稳定性

  • 增强异常关机后的搜索索引写入保护与恢复能力。“诊断与修复 → 高级维护”新增“断电恢复检查”，可先检查索引状态，再按结果分别确认恢复当前索引、切换可用旧索引或保留原索引后重建。原始素材不受影响，恢复备份不会自动删除。
  • 修复部分标称 16GB 内存的电脑因硬件保留内存、系统报告容量略低于 16GB 而无法启用 CPU 语音转写的问题；运行时仍会检查实际可用内存。

升级与兼容性

  • 可在“系统设置”中检查更新，并同步检查配套组件。智能分类候选、剪映联动、本地视觉描述和程序小包更新需要匹配的组件；Premiere Pro 联动还需要单独安装配套插件。
  • 新版 NVIDIA 搜索与本地视觉使用 CUDA 13，要求显卡计算能力至少 7.5、Windows 驱动至少 580.88。本地视觉仍至少需要 4GB 显存，推荐 6GB，不提供 CPU 推理。
  • Maxwell、Pascal、Volta 架构显卡（包括 GTX 1050 Ti）不再用于新版搜索的 CUDA 加速，搜索会回退 CPU；这些显卡无法运行新版本地视觉描述。CPU 与 AMD 搜索组件不适用这组 NVIDIA 门槛，分镜、人脸和语音组件按各自运行要求启用。
  • 升级前可备份应用数据，并保持素材源和数据磁盘可访问。仅更新运行组件不会使已有搜索索引或视觉描述失效；本地视觉失败时也不会自动切换到外部 API 上传图片。
