适用系统：Windows x64

发布通道：stable

发布状态：已发布

版本概览

v2.2.0 为素刀（ClipKnife）加入人物索引与人物素材整理，并改进语音转写、智能检索、视频分镜理解及大素材库的处理效率。同时完善离线组件安装、设备许可恢复和隐私设置。以下内容依据当前桌面端代码整理，正式发布信息以更新提示为准。

人物索引与素材整理

  1. 素材库新增“人物”视图。开启人物索引后，可在本机分析图片、相机 RAW 和视频分镜中的人脸，按人物查看相关图片与分镜；人物索引默认关闭。
  2. 支持为人物设置多个名称或别名、合并分组，以及手动移动图片或分镜的归属。智能搜索可按人物名称和别名查找对应素材，视频详情也可查看每个分镜识别到的人物并按人物筛选。
  3. 改进视频中的连续出场识别、跨分镜归组和历史索引续跑，减少同一人物被拆成多个分组及低质量画面造成的误归类。人物结果仍可能漏检或误分，可通过上述整理操作修正；更新不会覆盖已有人工整理结果。
  4. 人物列表、详情和素材选择改用分页与按需加载，改善大素材库中的浏览和检索等待；分析任务会按设备资源调整处理量，并在搜索或播放期间让出资源。

检索、分镜与语音

  1. 优化智能搜索的相关性与常见短关键词查询速度，并改善智能搜索组件的启动、重试及索引恢复。
  2. 外部视觉描述现在综合分镜中多个采样画面，帮助识别单张代表帧之外的内容；采样仍不能覆盖视频中的每一瞬间。
  3. 改进视频索引、分镜处理和音频切分的资源利用率，降低大批量处理时的等待；按本机硬件调整视频与人物索引调度。
  4. 改进语音转写组件及适用硬件的识别与回退提示。转写仍需在设置中开启，并安装与设备匹配的组件和模型。

素材、创作与任务体验

  1. 支持将常见相机 RAW 图片纳入素材库，用于预览、索引和搜索；派生预览保存在本地缓存，不修改原始文件。具体格式能否解码仍取决于相机文件及随应用提供的解码能力。
  2. 改善缩略图缓存和首次建库期间的图片展示，减少占位图长时间不更新的情况。
  3. 标签改为由用户维护；标签同步按批次显示在任务中心。创作助手新增外部素材库总开关，默认关闭，并支持在单个会话中覆盖该设置。
  4. 优化任务分页、重复任务检查、素材目录首次打开和任务提示，便于在大库中查看进度及定位处理状态。

安装、许可与隐私

  1. 完善与当前版本匹配的离线组件安装。使用完整且匹配软件版本、硬件类型的安装介质时，可从本机安装配套组件；缺少或不兼容的组件可联网补装。
  2. 改进部分服务无法正常启动的问题，修复大数据量下的综合建库、检索性能，优化整体处理时间。
  3. 系统设置新增使用统计与隐私说明。使用统计默认开启，可在设置中关闭；统计限于功能使用计数和脱敏硬件信息，不上传原始素材、完整本机路径、搜索词或转写文本。

升级提示

  • 正式发布后，可在“系统设置”中检查更新；首次安装入口见官网首页下载区。
  • 升级前可在“系统设置”中备份应用数据，并确保素材源、索引目录所在磁盘可正常访问。
