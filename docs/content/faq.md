# ClipKnife 常见问题

更新时间：2026-08-03
适用版本：v1.0.1 起

![诊断与修复入口示意](../assets/manual/08-diagnostics.png)

## ClipKnife 需要联网吗？

核心素材处理以本地环境为主。素材扫描、索引、搜索、视频分镜、代表帧抽取和语音转写都围绕本机运行。

联网能力主要用于辅助功能，例如检查更新、拉取通知、标记通知已读。远程服务不承担本地素材内容处理职责。

## 我的素材会被上传吗？

不会因为建库、搜索、分镜或转写而上传原始素材。ClipKnife 的产品边界要求素材文件留在用户电脑中，诊断包也默认不复制素材源文件。

诊断包只用于问题排查，默认脱敏路径，不包含用户素材源文件，搜索历史默认不导出。

## 支持哪些素材类型？

当前素材库支持图片、视频和音频。

图片会直接进入视觉检索索引。视频会先分镜，再抽取分镜代表帧进入视觉检索索引。音频会转写成文本后进入语音检索索引。开启视频语音转写后，视频里的语音内容也可以参与语音搜索。

## 可以添加整个盘符或外接硬盘吗？

可以。素材源可以是普通文件夹、整个盘符或外接硬盘路径。

添加盘符级或范围较大的素材源时，ClipKnife 会执行预检，并建议使用排除规则，避免扫描系统目录、缓存目录、开发依赖目录和 ClipKnife 自身工作目录。

## 移除素材源会删除原始文件吗？

不会。移除素材源只会移除 ClipKnife 对该范围的管理，不代表删除原始素材文件。

同样，从项目中移除素材也只影响项目本身，不会删除原始素材文件。

## 为什么刚添加素材后搜索不到？

素材需要先完成扫描、入库和索引。图片通常直接进入视觉索引；视频需要先分镜、抽取代表帧，再建立索引；音频需要生成转写后才能参与语音搜索。

如果刚添加素材就搜索不到，可以先到任务中心查看是否还有等待中、处理中或失败任务。

## 智能搜索和素材库搜索有什么区别？

素材库搜索主要搜索文件名、路径和标签等元信息。

智能搜索使用自然语言检索图片、视频片段和音频/视频语音内容。比如你可以输入“海边日落”“红色包装特写”或“会议里提到预算调整”。

## 搜索没有结果怎么办？

可以按这个顺序检查：

1. 换一个更具体的描述。
2. 确认当前搜索模式没有限制过窄。
3. 查看任务中心，确认索引任务是否完成。
4. 检查素材源是否仍可访问。
5. 前往诊断入口检查搜索服务和本地组件状态。

## 以图搜图不能用怎么办？

以图搜图需要当前图片或视频代表帧拥有可用的相似检索索引 ID。如果页面提示无法进行以图搜图，通常说明相关索引缺失、失败或失效。

你可以先查看任务中心的失败任务，再根据提示重试任务或重新构建 AI 索引。

## 视频搜索是搜索整个视频吗？

视频视觉搜索主要基于分镜代表帧。ClipKnife 会把视频切分成分镜，再抽取代表帧进入视觉索引。搜索结果会回连到原视频和对应时间段。

这意味着 ClipKnife 不承诺自动理解完整视频语义，搜索质量会依赖分镜和代表帧索引质量。

## 可以搜索视频里的说话内容吗？

可以，但需要开启视频语音转写。音频素材始终会生成可搜索转写；视频素材需要在系统设置中开启视频语音转写后，才会生成视频语音转写任务。

开启后，视频中的语音内容可以进入语音检索索引，搜索结果仍会保留视频身份，方便回到视频上下文。

## 分镜编辑会修改原始视频吗？

不会。调整分镜起止时间、编辑备注和标签、合并、分割或删除分镜，作用于 ClipKnife 的分镜记录和项目工作流，不会直接破坏原始视频文件。

导出片段会生成新的输出文件，便于后续剪辑或归档。

## 项目删除会影响原始素材吗？

删除项目会删除项目记录和项目文件夹中的导出内容，操作不可撤销。但原始素材文件不会因此被删除。

从项目中移除素材只影响当前项目。移除分镜会删除项目内生成的分镜文件，原始视频不会被删除。

## 外接硬盘断开后会怎样？

如果外接盘断开或路径失效，ClipKnife 会提示素材源异常。这个异常不应影响其他可用素材源继续工作。

重新连接外接盘后，如果盘符或路径发生变化，建议检查素材源状态，并根据需要重新扫描或修复。

## 任务失败怎么办？

先进入任务中心查看失败原因。常见处理方式包括：

- 修复或恢复源文件。
- 重新连接外接盘。
- 重试失败任务。
- 重新建库。
- 前往诊断与修复检查本地组件。

修复操作会先执行预览，确认后才写入任务或标记索引记录。

## 诊断包里有什么？

诊断包用于问题排查，默认只包含环境、任务、索引和日志摘要。它默认脱敏路径，不复制素材源文件，搜索历史默认不导出。

如果需要把诊断包提供给作者或支持人员，建议先确认页面提示的导出范围。

## 支持云同步、账号或多人协作吗？

当前不包含账号系统、云同步、多人协作、在线素材市场和商业化付费逻辑。

ClipKnife 当前重点是本地素材管理、本地 AI 索引、自然语言搜索、分镜、语音转写、项目和诊断维护。

## 检查更新有什么作用？

系统设置提供检查更新入口。ClipKnife 可以检查 stable 发布渠道中的最新版本，并区分全量安装包和增量更新包。

存在可用更新时，你可以查看更新说明、更新包类型、全量更新阈值，并下载更新。

如果当前版本落后多个已发布版本，更新提示会按版本从新到旧列出期间所有更新说明，避免遗漏中间版本内容。

检查更新也会比较 imsearch 与 TransNetV2 的本机版本和最新版本。组件需要更新时，应用会提供软件网盘入口；下载对应组件压缩包后，请到“系统设置 → 组件管理”确认替换。组件包不会静默自动安装。

## 创作助手的模型供应商从哪里来？

“创作助手设置 → 模型配置”左侧的固定供应商由素刀服务端提供，包含供应商名称、API Base URL、模型 ID 选项、每个模型的上下文长度，以及可选的配置说明简介和链接。固定供应商只能选择服务端提供的模型 ID，上下文长度也由服务端按模型设置；有配置说明时，客户端会通过 warning 提示卡展示，并在供应商提供链接时附上完整教程入口。你也可以添加自定义供应商并自行输入模型 ID 和上下文长度，但仅支持 OpenAI Compatible 协议；上下文长度默认是 256k（262,144 tokens）。自定义供应商可以在二次确认后删除；历史会话内容仍会保留，但依赖该供应商的会话无法继续对话。暂时离线时会使用同一远程服务最近一次成功获取的供应商目录；没有缓存时仍可使用已有本地配置。

## 创作助手的 API Key 会上传到素刀服务端吗？

不会。素刀服务端只下发供应商的公开配置元数据，API Key 保存在桌面端本地私有配置中。测试连接和实际创作请求会直接访问你配置的模型供应商，请根据该供应商的隐私政策决定是否使用。

## 工具箱

### 工具箱有哪些工具，为什么需要单独安装？

当前客户端适配了文本转语音、基于 Real-ESRGAN 的图片清晰化，以及基于 Video2X 的视频分辨率/帧率增强。工具种类和使用界面需要随客户端版本一起适配，服务端只负责记录这些已知工具的版本和下载地址，不能动态加入客户端不认识的工具。第三方工具体积较大且更新节奏不同，因此按需下载安装；素刀会在启用前校验压缩包和包内文件。

### 图片或视频增强为什么无法开始，或者处理很慢？

先确认对应工具已经安装，并检查显卡是否支持 Vulkan。更高放大倍数、TTA、RIFE UHD 和“先提升分辨率，再提升帧率”都会增加显存、磁盘占用和处理时间。可以先用较短素材、2× 倍数和默认模型测试；显存不足时，图片工具可改用较小分块。处理可随时取消，素刀不会覆盖原始图片或视频。

### 文本转语音生成失败后，输入正文会留在任务记录里吗？

不会。任务中心只记录工具、音色、进度、结果文件和错误状态等必要信息，不保存输入正文。从工具详情生成的 WAV 文件会保存在应用管理的工具箱输出目录，可在“最近生成”中试听或在文件夹中显示；从创作助手生成的 WAV 文件会直接保存在对应会话工作区，不会出现在工具箱的“最近生成”列表。
