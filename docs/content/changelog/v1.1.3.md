# v1.1.3

发布日期：2026-08-03
适用系统：Windows
发布通道：stable

## 更新内容

1. 优化分镜预览，修正分割位置偏差。
2. 视频详情页增加自动联播功能。
3. 高级筛选增加横版、竖版画面筛选。
4. 移除素材源时，支持同时删除对应索引。
5. 新增组件替换功能；后续可直接替换组件，不影响本地数据。
6. 修复部分已知问题。
