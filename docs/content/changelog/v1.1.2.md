# v1.1.2

发布日期：2026-08-01
适用系统：Windows
发布通道：stable

## 重要更新

1. 优化底层检索模式，支持混合检索、视觉优先、文本优先和自定义标签。
2. 新增素材盘模式；外接素材盘可在不同电脑上快速检索，无需重复建库。
3. 修复超时、大数据量异常、HEVC 视频预览失败等已知问题。

## 本体更新

1. 新增组件替换功能，本体与组件可分别更新，保护本地数据。
2. 智能检索时可指定素材源或文件，缩小检索范围。
3. 新增“补全缺失索引”功能，无需全量重建。
4. 新增自定义数据文件存放位置。
5. 优化交互样式、以图搜图和素材对账等功能。

## 下载与升级

- 增量安装包：[素刀 v1.1.2 x64 安装程序](https://gitee.com/qianqianhaiou/clip-knife-doc/releases/download/v1.1.2/%E7%B4%A0%E5%88%80_1.1.2_x64-setup.exe)
- 全量安装包：[百度网盘](https://pan.baidu.com/s/1siqtqe_1p0KLItu944sflQ?pwd=i5ja)

> 本次 `imsearch` 和 `transnetv2` 组件也有更新。请从网盘的 `external` 目录下载组件包，然后在“系统设置 → 组件管理”中依次替换。

> 从低于 v1.1.0 的版本升级时，请下载全量安装包；安装前请完全卸载旧版，并在卸载时勾选删除应用数据。
