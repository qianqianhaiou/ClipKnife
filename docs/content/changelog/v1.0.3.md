# v1.0.3

发布日期：2026-07-04
适用系统：Windows
发布通道：stable

## 更新内容

1. 底层重构，提升建索引速度。
2. 新增项目管理；右键素材可添加到项目，并支持将整个项目拖拽到剪辑软件导入区。
3. 新增以文搜音频，可通过文字搜索音频内容。
4. 优化批量任务处理；坏点素材会跳过并提示，不再轻易卡住整个队列。
