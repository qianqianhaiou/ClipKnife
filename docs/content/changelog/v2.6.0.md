# v2.6.0

发布时间：2026-10-30
适用系统：Windows x64
发布通道：stable
发布状态：已发布

本次更新集中改进素材管理与查找体验：重新整理工作区、素材库和智能搜索，合并项目与分类分组，简化首次初始化，并增强异常退出后的索引恢复能力。

## 全新UI

- 主导航调整到窗口顶部，集中提供素材库、智能搜索、创作工具和任务中心入口；系统设置位于右上角。统一素材卡片、详情面板、人物分组、通知和常用弹窗的布局与状态反馈。
- 素材总览、人物分组和智能分类共用文件夹、素材类型与分类侧栏，方便在同一范围内切换浏览。目录按需加载，侧栏与分区记住展开状态，窄内容区通过抽屉筛选。
- 素材详情改为连续阅读面板，集中查看预览、文件信息、标签、AI 描述和视频分镜；切换素材时及时取消旧请求，改善连续浏览与加载反馈。
- 改进横竖屏素材混排、缩略图占位和原文件分辨率显示，修复新导入相机 RAW 图片的尺寸与方向识别。历史素材不会仅因升级自动补采分辨率。

## 智能搜索

- 搜索首页使用本机素材构成曲面照片墙，并展示已有标签、画面词条或可点击的参考图片，方便从库内内容开始搜索。背景按设备实际表现选择效果，性能不足时降级，并遵循系统减少动态效果的偏好。
- 优化搜索框、筛选区域、结果列表与详情面板的衔接，改善图片预览、视频分镜浏览及窄窗口下的可读性。
- 点击搜索框的清除按钮会取消尚未完成的搜索与加载请求，清空结果并返回初始界面；仅手动删空文字仍保留当前结果。
- 修复标签命中依据显示，改善照片墙缩略图按需生成与加载，减少初次进入搜索页时的卡顿。

## 智能分类与分组

- 原“项目管理”合并到智能分类分组。首次读取时，旧项目自动迁为手动分组，保留名称、描述和素材成员；空项目、离线素材与失效分镜记录也会保留，重名分组会加以区分。
- 素材库、搜索结果和视频详情统一提供“添加到分组”。图片、完整视频、音频和分镜可手动入组，同一素材可属于多个分组；重复添加不会产生重复成员，移出或删除分组不删除原始素材。
- 重新整理分类创建与候选确认流程，可按名称、参考图或画面词条建立规则，查看真实匹配依据、视觉描述和分镜范围。智能候选仍需用户确认后才归类。
- 每次匹配最多保存 200 项候选，支持滚动加载、批量确认、忽略，以及清空本批待确认后撤销。已保存的候选不会因确认、忽略或刷新自动补满，需要新一批时主动重新匹配。
- 改善多选、目录与分类筛选、空结果提示及匹配失败重试；修复图像组件尚未就绪时分类匹配失败的问题。智能匹配仍面向本机图片与视频分镜。

## 单文件导入与首次初始化

- 单独添加文件采用一次性导入，汇总在“单独添加的文件”中；不持续监听同目录，也不自动扫描旁边的其他文件，原文件保留在原位置。需要持续跟踪目录时，仍可配置文件夹素材源。
- 首次使用可先选择或拖入少量视频、图片，再选择应用数据位置并自动准备必需环境；原有流程保留在“高级初始化”。语音转写、人物索引与可选创作工具仍按需启用。
- 初始化分别显示下载、校验、解压和模型启动的实际进度。环境就绪后后台处理所选素材，可提前进入搜索，失败项单独显示，不计为已完成。
- 新增“从素材库移除”：确认后移除应用记录及相关索引、标签、分组关联，保留原文件；监听、重扫或重启不会自动把该路径重新加入，主动重新添加文件后才解除排除。
- 本地素材另提供“永久删除原文件”，与从库中移除分别确认：需核对完整路径、输入完整文件名并确认不可恢复，删除不经过回收站。当前仅支持能够验证身份的 Windows 本地 NTFS/ReFS 普通文件，每次处理一项；共享素材、目录、文件变化或占用等情况会拒绝删除。

## 任务、启动与工具体验

- 任务中心精简列表并支持行内展开素材明细，改进状态页签、进度、错误信息、素材预览与底部分页；首次读取失败明确显示未获取状态。
- 修复“全部暂停”影响后续任务调度的问题：暂停现有任务后，新提交的任务仍可正常进入调度。
- 新增独立启动页，展示素刀 Logo 动画与实际启动、更新状态；动画完成后仍会等待服务就绪。启动或主界面加载失败时提供对应的重试与诊断入口，修复部分场景启动白屏的问题。
- 工具与模型资源安装采用独立调度，普通索引、转写任务运行时可继续下载和准备资源；同一组件正在使用或资源不足时明确显示等待原因。
- 改善视频理解任务断连后的会话恢复与有限重试，修正部分语音转写句尾时间戳异常，调整创作工具的自适应布局。

## 索引恢复与稳定性

- 修复多帧索引尚未完成就被提前用于搜索、记录更新中断，以及恢复记录异常导致搜索启动受阻等问题。
- 对可确认的不完整索引记录，配套组件可先备份并保留正常记录，仅安排异常素材补建；通过检查后正常记录即可搜索，补建进度可跨重启接续。真实文件损坏等情况仍需按检查结果处理，不以局部恢复代替完整校验。
- 明确区分正在检查、等待重试与需要用户处理的恢复状态，保留手动暂停和恢复操作的确认边界，改善连续中断、组件修复及许可暂时不可用后的恢复。
- 改进符合条件的 NVIDIA 设备上的视频分镜与图像编码调度；显存或内存余量不足时仍采用串行处理，不承诺固定加速比例。

## 升级说明

- 在“系统设置”中检查软件及配套组件更新。分类匹配、索引局部恢复等改进需要匹配的新版图像组件；升级前可备份应用数据，并保持素材源与数据磁盘可访问。
- 旧项目迁为分组后，不再自动准备项目片段或提供原项目整组拖拽；已有导出文件保留，原文件拖拽与手动“导出片段”继续可用。这里的分组与剪映草稿、Premiere 项目相互独立。
- 创作助手暂时移出主导航，可从“系统设置 → 诊断与修复 → 进入创作助手（临时入口）”打开。
- 本版本不改变此前的 [CUDA 13 显卡兼容要求](../v2.4.0/)。
